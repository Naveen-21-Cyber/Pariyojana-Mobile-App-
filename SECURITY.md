# Security Policy — Pariyojana

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Pariyojana takes security and local data privacy seriously. If you discover a security vulnerability or potential data leak:

1. **Do NOT open a public GitHub issue.**
2. Send an email directly to the maintainer: **Naveen Telasang** (`urtemp69@gmail.com`).
3. Include detailed steps to reproduce the issue, along with any relevant proof-of-concept logs or context.

### Response Timeline
- **Acknowledgement:** Within 24–48 hours
- **Assessment & Patch:** Within 7 days for critical findings

Thank you for helping keep Pariyojana secure for everyone!
